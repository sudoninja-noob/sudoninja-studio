Quick start

Run it locally in one command

The app has two parts — a React frontend and the ACE-Step Python backend (GPU/MPS). One script starts both.

# from the repo folder — starts backend + frontend together ./start.sh # then open http://localhost:5173
# backend only (macOS · Apple Silicon) ACESTEP_INIT_LLM=true ./start_api_server_macos.sh
# frontend only cd frontend npm install npm run dev
⚠️ The backend needs a GPU/MPS machine and can’t run on GitHub Pages — it serves the actual model. This page is the project’s landing/showcase; the full app runs locally or on a GPU host. See RUNNING.md in the repo for the complete guide.
Under the hood

Architecture

A typed React SPA talks to the ACE-Step FastAPI backend over HTTP. Your history and library live in the browser — nothing is sent to a third party.
